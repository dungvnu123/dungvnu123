<h2>👋 About me</h2>

<p>
  I'm an <b>AI Engineer</b> who builds end-to-end AI products: from training and evaluating models to serving them
  through reliable backend APIs. My main focus is <b>Computer Vision</b> (detection, tracking, depth and distance
  estimation, OCR) and <b>LLM-powered applications</b>, backed by solid backend engineering in Python, Node.js and Go.
</p>

<ul>
  <li>🔭 Currently researching a <b>monocular-camera ADAS</b>: vehicle detection with YOLOv8, metric depth, relative speed and forward collision warning.</li>
  <li>🧠 Working with <b>LLMs</b> to build assistants, document understanding and retrieval-based applications.</li>
  <li>⚙️ Designing <b>REST APIs and services</b> with NestJS, FastAPI, Django and Go to put models into production.</li>
  <li>🌱 Always learning: model optimization, MLOps and scalable system design.</li>
</ul>

      <h3>🚗 Monocular ADAS: Forward Collision Warning</h3>
      <p>
        Scientific research project. A single dashcam is used to detect and track vehicles with <b>YOLOv8</b>, estimate
        distance in metres (<b>Depth Anything V2</b> metric depth, pinhole and ground-plane geometry), relative speed
        and <b>time-to-collision</b>, then raise <code>WARNING</code> / <code>CRITICAL</code> forward collision alerts.
